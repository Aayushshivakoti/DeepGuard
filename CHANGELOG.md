# Changelog

All notable changes to this project will be documented in this file.

## [3.1.0] - 2026-08-23
### Added
- Real spatial EfficientNet-B4 & voice clone 1D CNN ML model weights loaders.
- Advanced threat verification engines (PDF JS exploit scans, EML header audit, typosquatting checking).
- Security hardening (Double submit CSRF, private IP SSRF block, file magic byte checks).
- S3/MinIO cloud storage helper.
- Splunk/Elasticsearch/Datadog SIEM event logs shipping exporter.
- AWS WAF / Cloudflare SOAR IP blocking rules playbooks.
- Prometheus `/metrics` exporter endpoint.
- WebSockets real-time status alerts pipeline.
- Front-end Teams CRUD dashboard, comparison overlay, password recovery, email validation, and public hash check.
- Cross-browser Manifest V3 extension ports with inline badges overlay content script.
